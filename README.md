# ICU Chest X-Ray Benchmarking

Benchmarking harness for evaluating chest X-ray foundation models on ICU-relevant tasks, using MS-CXR-T as the primary dataset.

## Tasks

### 1. Temporal Classification
Given a (prior, current) portable CXR pair, predict whether a finding is **improving / stable / worsening**.

- Dataset: [MS-CXR-T](https://physionet.org/content/ms-cxr-t/1.0.0/) — 1,326 annotated pairs, 5 findings, 800 subjects
- Primary protocol (Protocol A): frozen encoder + linear probe, subject-level 70/10/20 split, 4 seeds
- Also replicates BioViL-T paper (Table 2): trained on Chest ImaGenome silver labels, tested on full MS-CXR-T

### 2. Medical Device Classification
Detect and classify ICU medical devices (ET tube, central line, chest tube, etc.) in portable AP CXRs. Labels being generated by trained radiologists on the ~1,600 MS-CXR-T images.

### 3. Critical Finding Classification
Detect acute findings relevant to ICU care (pneumothorax, consolidation, edema, etc.). Same radiologist-labeled image set as Task 2.

### ImaGenome-trained temporal classifier — seed 42 (paper Table 2 protocol)

Per-finding macro-accuracy on full MS-CXR-T test set (1,035 pairs after filtering):

| Finding | BioViL-T (CXR + full FT) | Google CXR (CXR + MLP) | DN121 concat | DN121 attention | MAIRA-2 (specific) | MAIRA-2 (standard) |
|---|---|---|---|---|---|---|
| consolidation | **0.646** | 0.527 | 0.550 | 0.494 | 0.464 | 0.380 |
| edema | 0.605 | 0.616 | **0.645** | 0.643 | 0.332 | 0.342 |
| pleural_effusion | **0.690** | 0.650 | 0.662 | 0.628 | 0.317 | 0.351 |
| pneumonia | 0.613 | **0.638** | 0.581 | 0.621 | 0.337 | 0.350 |
| pneumothorax | **0.508** | 0.393 | 0.507 | 0.340 | 0.373 | 0.323 |
| **average** | **0.612** | 0.565 | **0.589** | 0.545 | 0.365 | 0.349 |

Observations (seed 42 only — take with error bars in mind):
- **CXR-specific pretraining helps, but only modestly**: BioViL-T beats a generic ImageNet DenseNet-121 (both fine-tuned end-to-end, concat head) by 0.023 average. The bulk of the benefit comes from full fine-tuning, not the CXR-specific representation.
- **Full fine-tuning > frozen probe, even across pretraining domains**: DenseNet-121 (ImageNet + FT) beats Google CXR (CXR + frozen-feature MLP) by 0.024. Google CXR can't be fine-tuned end-to-end (its SavedModel signature has a fixed batch=1).
- **Simple concat+MLP head beats attention head** (0.589 vs 0.545). The 2-token cross-attention (CLS queries [prior, curr] via single MHA layer) degenerates to a learned weighted average on only 2 tokens — doesn't provide useful inductive bias. A spatial cross-attention variant (196 tokens per image, 2-layer transformer decoder) was also tried but class-collapsed on small-dataset findings.
- **MAIRA-2 (generative) is near random** (0.349–0.365 vs 0.333 chance). The generate-then-classify pipeline loses signal: MAIRA-2 often omits temporal comparison language even when given both images, and LLM-based label extraction adds further noise. Finding-specific prompting helps on consolidation (+0.08) and pneumothorax (+0.05) by encouraging explicit comparison language, but doesn't rescue other findings. Direct discriminative models vastly outperform generative report→classify approaches on this structured task.
- **DenseNet-121 concat wins on edema** (0.645 vs 0.605 for BioViL-T) and is competitive on pleural_effusion and pneumothorax.
- **Pneumothorax is hard for every model** (< 0.51) — likely limited by the smallest ImaGenome training set and the most missing-image attrition.
- Remaining seeds (123, 456, 789) pending for error bars.

### Gotchas found during this run

- `train_finetune_imagenome_generic.py` required a **class-log-prior bias init** on the final head linear. With `nn.init.normal_(weight, std=0.01)` and zero bias, balanced-class findings (edema) were symmetry-locked at uniform predictions — loss pinned exactly at log(3)=1.0986, no gradient escape. Only the skewed-class findings (consolidation, weight 2.2 on rare class) broke the symmetry naturally.
- DenseNet-121 + fp16 AMP overflows mid-training — switched to bf16.

```bash
conda create -n ms-cxr-bench python=3.11
conda activate ms-cxr-bench
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
pip install scikit-learn pandas tqdm pyyaml
```

## Usage

**Protocol A (frozen encoder probe):**
```bash
# Extract features once, then train across seeds
python scripts/extract_biovil_t_features.py
python scripts/train.py --config configs/biovil_t_protocol_a_mlp.yaml

python scripts/extract_google_cxr_features.py
python scripts/train.py --config configs/google_cxr_protocol_a.yaml
```

**ImaGenome-trained probes (Table 2 comparable):**
```bash
# After MIMIC-CXR-JPG images finish downloading to /data/imagenome_images/

# BioViL-T: full end-to-end fine-tune on ImaGenome, test on full MS-CXR-T
python scripts/train_biovil_t_imagenome.py

# Google CXR: frozen encoder — extract features, then train MLP probe
# (run in a TF-capable env; train step is PyTorch-only)
python scripts/extract_google_cxr_imagenome_features.py
python scripts/train_google_cxr_imagenome.py

# Our model: end-to-end fine-tune (once model is integrated)
python scripts/train_finetune_imagenome_generic.py --model ours
```

**Zero-shot (Protocol C):**
```bash
python scripts/eval_protocol_c_biovil_t.py
```
