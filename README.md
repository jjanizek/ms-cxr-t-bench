# ICU Chest X-Ray Benchmarking

Benchmarking harness for evaluating chest X-ray foundation models on ICU-relevant tasks, using MS-CXR-T as the primary dataset.

## Tasks

### 1. Temporal Classification
Given a (prior, current) portable CXR pair, predict whether a finding is **improving / stable / worsening**.

- Dataset: [MS-CXR-T](https://physionet.org/content/ms-cxr-t/1.0.0/) — 1,326 annotated pairs, 5 findings, 800 subjects
- Primary protocol (Protocol A): frozen encoder + linear probe, subject-level 70/10/20 split, 4 seeds
- Also replicates BioViL-T paper (Table 2): trained on Chest ImaGenome silver labels, tested on full MS-CXR-T

### 2. Medical Device Classification
Detect and classify ICU medical devices (ET tube, central line, chest tube, etc.) in portable AP CXRs. Labels being generated by trained radiologists on the ~1,600 MS-CXR-T images.

### 3. Critical Finding Classification
Detect acute findings relevant to ICU care (pneumothorax, consolidation, edema, etc.). Same radiologist-labeled image set as Task 2.

## Setup

```bash
conda create -n ms-cxr-bench python=3.11
conda activate ms-cxr-bench
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
pip install scikit-learn pandas tqdm pyyaml
pip install health_multimodal  # BioViL-T
```

Data symlinks:
```bash
ln -s /data/ms-cxr-t-relabel data/raw/images
ln -s ~/Downloads/MS_CXR_T_temporal_image_classification_v1.0.0.csv data/raw/ms_cxr_t_labels.csv
```

## Usage

**Protocol A (frozen encoder probe):**
```bash
# Extract features once, then train across seeds
python scripts/extract_biovil_t_features.py
python scripts/train.py --config configs/biovil_t_protocol_a_mlp.yaml

python scripts/extract_google_cxr_features.py
python scripts/train.py --config configs/google_cxr_protocol_a.yaml
```

**ImaGenome-trained probes (Table 2 comparable):**
```bash
# After MIMIC-CXR-JPG images finish downloading to /data/imagenome_images/

# BioViL-T: full end-to-end fine-tune on ImaGenome, test on full MS-CXR-T
python scripts/train_biovil_t_imagenome.py

# Google CXR: frozen encoder — extract features, then train MLP probe
# (run in a TF-capable env; train step is PyTorch-only)
python scripts/extract_google_cxr_imagenome_features.py
python scripts/train_google_cxr_imagenome.py

# Our model: end-to-end fine-tune (once model is integrated)
python scripts/train_finetune_imagenome_generic.py --model ours
```

**Zero-shot (Protocol C):**
```bash
python scripts/eval_protocol_c_biovil_t.py
```
